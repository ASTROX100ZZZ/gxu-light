# 南门红绿灯 · 安卓 App（手机 + 手表）

同一工程两个模块：

| 模块 | 产物 | 功能 |
|---|---|---|
| `app/` | 手机 APK | 完整功能（与网页版同一套页面）+ **桌面小组件**每秒刷新灯态，不用打开 App 一眼看到 |
| `wear/` | 手表 APK（Wear OS） | 大色块大秒数抬腕即看 + 点按"变红/变绿"校准 + 长按微调配时 |

电脑端不需要 App，继续用网页版即可。

## 一、编译（约 30 分钟，全免费）

1. 下载安装 **Android Studio**（官网免费，任何版本 ≥ Hedgehog 均可）；
2. 打开 Android Studio → **Open** → 选择本 `android/` 目录；
3. 首次打开会自动下载 Gradle 和依赖（需要联网，耐心等进度条）；
4. 同步完成后：
   - **手机版**：菜单 Build → Build App Bundle(s)/APK(s) → **Build APK(s)**，
     产物在 `app/build/outputs/apk/debug/app-debug.apk`；
   - **手表版**：左上方运行配置切换到 **wear**，同样 Build APK(s)，
     产物在 `wear/build/outputs/apk/debug/wear-debug.apk`。

## 二、安装与使用

### 手机

1. 把 `app-debug.apk` 发到手机（微信文件传输助手/数据线/网盘均可），点击安装
   （系统提示"未知来源"时允许一次）；
2. 打开 App——界面和网页版完全一致，校准、拟合、备份功能都在；
3. **加桌面小组件**：长按手机桌面空白处 → 小组件 → 找到"南门红绿灯"拖到桌面。
   添加后小组件每秒刷新当前灯态和剩余秒数；
4. 首次添加小组件时如通知栏出现"红绿灯小组件运行中"，这是安卓对
   每秒刷新服务的强制要求，把该通知设为"最小化/静默"即可，不影响使用。

> 数据说明：App 内的校准/拟合数据与小组件自动同步（网页里每次保存都会推送参数给小组件）。
> App 与网页版数据各自独立，可用"导出备份 / 导入恢复"互相搬家。

### 手表（Wear OS：华为 GT 以外的安卓手表、小米手表 S 系列、TicWatch、三星 Galaxy Watch 等）

1. 手表打开 开发者模式 + ADB 调试（设置 → 关于 → 连点版本号）；
2. 电脑命令行（Android Studio 自带 platform-tools）：
   ```
   adb install wear-debug.apk
   ```
   或在 Android Studio 里直接选 wear 运行到已配对的手表；
3. 手表上打开"南门红绿灯"：
   - 看到灯**刚变红**就点「变红」、**刚变绿**就点「变绿」，即完成校准；
   - 配时不准时长按中间秒数，出现 R±/G± 微调按钮，调完点 ✓。

> 手表端为独立极简版：数据只存在手表上，不参与拟合，校准靠点按。

## 三、常见问题

- **耗电**：小组件每秒刷新需要常驻服务，实测与普通时钟小组件耗电相当；
  如介意，可把 `WidgetUpdateService.kt` 里的 `postDelayed(this, 1000)` 改成 `60000`（分钟级刷新）。
- **iPhone / Apple Watch**：需要 macOS + Xcode 才能编译（免费签名 7 天一续），
  Windows 环境做不了；iPhone 用户建议浏览器打开网页版 → 分享 → 添加到主屏幕。
- **网页版改动后**：把新版 `index.html` 覆盖到 `app/src/main/assets/index.html`，重新编译即可。
