# 🚦 南门红绿灯 · 广西大学

广西大学南门西侧路口红绿灯倒计时工具：打开即看当前灯态和剩余秒数，帮你算好出发时间，走到路口正好绿灯。

## 在线使用（无需安装）

**网页版（手机/电脑通用）：https://gxu-south-gate-light.app.workbuddy.host/**

## 下载安装（Release 页面）

| 安装包 | 平台 | 说明 |
|---|---|---|
| `app-debug.apk` | 安卓手机 | 完整功能 + **桌面小组件**（每秒刷新，不用打开 App 一眼看到灯态） |
| `wear-debug.apk` | Wear OS 手表 | 大色块大秒数抬腕即看 + 点按"变红/变绿"校准 |

手机安装：下载 APK → 点击安装（允许"未知来源"）→ 长按桌面空白处 → 小组件 → 拖出"南门红绿灯"。

## 功能

- 🚥 **实时灯态**：红/绿灯剩余秒数大字显示（初始配时 红 101s / 绿 40s）
- 🎯 **观测校准**：在路口报一次读秒（灯色 + 剩余秒数）即可校准，时间戳本地打戳、自动扣除反应延迟
- 🧮 **配时拟合**：多次观测自动反推真实红/绿时长（网格搜索 + 加权最小二乘），初始估计值会被数据自动修正
- 🛡️ **防捣蛋**：异常输入自动拦截降权，拟合时离群样本自动剔除
- 🚶 **出发建议**：输入步行时间，告诉你"现在出发"还是"等 X 秒再出发"，附未来 3 个绿灯窗口
- 💾 **备份迁移**：数据本地优先存储，一键导出/导入 JSON 备份

## 声明

配时数据来自人工观测与拟合，可能与实际配时有偏差；仅供出行参考，过马路请遵守交通规则、看灯不看手机。
